# Interactive Video Generation Website

A simple GitHub Pages website for the Bias Video Series. It presents the ten planned videos, their current status, and a high-level production checklist.

## Local preview

Run a static server from this directory, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publishing

The site is designed to publish directly from the repository's `main` branch with GitHub Pages.
